# Report templates (v1)

## Daily summary (sent each working day)
1. **Done** since the last summary (with links)
2. **Next** (today and tomorrow)
3. **Blockers** (who or what is stuck, since when)
4. **Test pass rate** (passed / total, trend; "no tests yet" if none)
5. **Decisions needed from Enahoro** (one line each, with a recommendation)
6. **Human tasks** due or overdue (from HUMAN_TASKS)

## Milestone report (at each phase gate)
1. Gate and date; approval requested (yes/no)
2. **Built vs mocked**: table of each capability marked REAL, DEMO or NOT STARTED; nothing counted as working unless tested for real
3. Test results (Codex): pass/fail/pending, CI status
4. Security and accessibility status (WCAG 2.2 AA, 320 px and up)
5. Compliance review status (Osaretin) and open DPIA items
6. Sprint metrics: planned vs done, carry-over, bugs opened/closed
7. Cost against the free tier and budget
8. Risks and mitigations
9. Decisions and human tasks outstanding
10. Approval request and what happens next
