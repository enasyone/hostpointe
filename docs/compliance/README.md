# Compliance (owner: Osaretin Igbinedion, on call)

Documents to be drafted in Phase 0 (story P0-10):

- `DPIA.md`: Data Protection Impact Assessment for guest data, Safe Pickup (children's data), messaging consent, and UK–Nigeria data transfers.
- `DATA_MAP.md`: what personal data is collected, where it's stored, who can see it, and how long it's kept.
- `THREAT_MODEL.md`: security threats and their controls.
- `RETENTION.md`: retention and purge schedule (for example, location data purged 24–72 hours after an event, once Phase 4 exists).

Rules in force now:
- Safe Pickup uses matching codes only, with no location tracking (D-003).
- Feedback is anonymous by default, stored separately from check-in records (D-014).
- No message is sent without recorded consent; opt-out is always respected.
- No personal data goes into QR codes or is sent to AI by default.
- Marketing never promises guaranteed child safety.

Laws and codes: UK GDPR (General Data Protection Regulation), the ICO (Information Commissioner's Office) Children's Code, PECR (Privacy and Electronic Communications Regulations), and Nigeria's NDPA (Nigeria Data Protection Act) 2023. This is guidance, not legal advice.
